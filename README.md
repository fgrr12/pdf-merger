# Grapa

App de escritorio para unir varios PDFs en uno solo. Arrastrás los archivos, los
acomodás mirando la miniatura de cada uno, y listo.

Tauri 2 + React 19 + TypeScript + Tailwind 4.

```bash
pnpm install
pnpm t:d     # desarrollo
pnpm t:b     # instalador en src-tauri/target/release/bundle/
```

La versión anterior en Python/tkinter quedó en [`legacy/`](legacy/).
